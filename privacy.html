Zásady ochrany soukromí

Hlídač pošty je osobní aplikace pro soukromé použití jediného uživatele (vlastníka této stránky). Slouží ke čtení vlastní e-mailové schránky Gmail za účelem přehledu o zásilkách a fakturách.

Aplikace přistupuje ke Gmailu výhradně v režimu jen pro čtení (rozsah gmail.readonly). Data z e-mailů se zpracovávají pouze v zařízení uživatele a na jeho vlastním soukromém serveru (Cloudflare Worker) a nejsou předávána žádné třetí straně, nejsou prodávána ani využívána k reklamě.

Použití informací získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

Přístup lze kdykoli odvolat na myaccount.google.com/permissions.
